## Full description

Basic Autocorrect is the autocorrect your browser is missing.

Type "dont" and press space, and it becomes "don't". Type "teh", get "the". Corrections happen the moment you finish a word, like on your phone: no popups, no suggestions to click, nothing to accept.

WHAT IT FIXES
• Missing apostrophes: dont → don't, cant → can't, wont → won't, im → I'm, youre → you're
• Common misspellings: teh → the, recieve → receive, definately → definitely, alot → a lot (about 4,300 high-confidence fixes)
• Capitalization: i → I, monday → Monday
• Your own corrections: add shortcuts like "myemail" → "me@example.com"

Words that could be real (its, ill, were, well) are never changed. URLs, email addresses, passwords and code editors are left alone.

TWO MODES
• Basic (default): the high-confidence list above.
• Aggressive: also fixes other misspellings when the intended word is clear (keybaord → keyboard). Names, slang and real words are left alone.

MADE FOR GOOGLE DOCS
Fills the gaps in Docs' own autocorrect, which skips words like "cant" and "wont". Also works in regular text boxes and editors across the web.

YOU'RE IN CONTROL
• Cmd/Ctrl-Z right after a correction puts back exactly what you typed.
• Add words to a "never correct" list with one click from the recent corrections list.
• Turn it off for any site, or everywhere, from the toolbar button.

PRIVATE BY DESIGN
Your keystrokes never leave your browser. No accounts, no servers, no analytics, no AI, no remote code. Your settings stay on your device.

## Chrome Web Store: Privacy practices tab

**Single purpose description**
Automatically corrects obvious typing and spelling mistakes in text fields as the user types, using correction lists bundled with the extension.

**Permission justification: storage**
Saves the user's settings on their device: on/off, correction mode, the user's own corrections, words to never correct, sites where it's turned off, and the last 10 corrections made (so the user can undo or block one). Nothing is synced or transmitted.

**Permission justification: host permissions (content script on all sites)**
Autocorrect has to work in whatever text field the user is typing in, on any website (Google Docs, email, forms, chat). The content script only looks at the few characters before the cursor when a word is finished, corrects it locally, and never reads pages or sends data anywhere.

**Are you using remote code?**
No, I am not using remote code. All code and word lists are included in the package.

**Data usage**
Check none of the data types. (The extension does not collect or transmit any user data.)
Then certify all three statements: not selling or transferring user data to third parties, not using it for unrelated purposes, not using it for creditworthiness or lending.

## Firefox (AMO): Notes to reviewer

Basic Autocorrect corrects typos locally as you type. No network requests, no remote code.

Generated files: src/engine/data-common.js, src/spell/words.txt and src/spell/known.bin are word data generated by scripts/build-data.mjs from public word lists (SCOWL, Wikipedia's list of common misspellings, and FrequencyWords; see NOTICE.md). known.bin is a Bloom filter of valid English words used by the optional "Aggressive" mode. The source package includes the build script. To regenerate: Node 20+, then `node scripts/build-data.mjs` (it downloads the three public sources).

The only fetch() call (src/spell/spell.js) loads the extension's own bundled files via runtime.getURL. That's why they are listed in web_accessible_resources.

To test: open any page with a text field (or a Google Doc), type "dont" and press space. It becomes "don't". Cmd/Ctrl-Z right after restores "dont". The toolbar popup has the settings.

No build step for the extension itself: the uploaded zip is the source as-is (plain JavaScript, not minified).
